# Velaroq

Velaroq is a developer productivity and workflow tool designed to help Flutter developers complete real development tasks more efficiently.

## Current Status

```text
Version: 0.0.x
Target Milestone: 0.1.0 — Code Generation Foundation
Status: In Development
```

## Current Goal

The current development stage focuses on building Velaroq's first reusable code generation foundation.

The first real capability is a Dart Model Generator:

```text
Developer Requirement
        ↓
Structured Data
        ↓
Python Rules
        ↓
Jinja2 Template
        ↓
Dart Model
```

Generated code follows the currently defined Flutter project coding conventions.

## Tech Stack

```text
Python      → Core Engine
Jinja2      → Code Templates

React       → Desktop UI
Tauri       → Desktop Shell
```

React and Tauri will be introduced in later development stages.

## Project Status

Velaroq is currently under active development.
